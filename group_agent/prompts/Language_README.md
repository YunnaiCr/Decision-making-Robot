# 语言层维护说明

本目录负责理解、规划、表达和纪要的提示词、常见叫法映射、虚构示例及反例。
当前提示词版本为 `2.0`，版本常量只用于识别内容；本轮没有修改调用方或运行日志格式。

## 边界

- 保持现有 `StateDelta`、`PlannerDecision`、`FinalDraft`、`MessageOut`、`Minutes` 契约。
- 本轮只修改本目录和 `tests/test_prompts.py`。不修改主循环、模型、校验器、工具、外部数据源或共享 fixtures。
- `planning.py` 仍沿用 `describe_tools()` 的现有导入，工具说明继续由真实签名生成。
  完全消除提示词对工具层的依赖需要调整编排层注入，本轮没有声称已解决该问题。
- `unknowns` 仍是普通字符串列表，保留原话、涉及的人和要求性质；没有引入新的可解析协议或约束类型。
- 本轮规则是对模型的指导，不是新增的确定性校验。不能据此宣称已经保证属性、营业、交通或成分要求。

## 词汇和要求

`vocab.py` 的别名和活动到品类的映射只是提示，不是允许清单，也不描述实时库存。
新活动可使用稳定的新标识；新品类、标签和属性以实际工具结果为准，不要求同步扩展静态白名单。
忌口保留准确食物语义，不能近似替换，也不能以缺少标签证明成分安全。

硬度根据语义及后续确认判断：明确上限、禁止、不可改时间和已拍板活动为 hard；
可协商偏好即使包含数字仍为 soft。活动提议不自动等于已确认活动。
多项 `want` 表示全部要做；二选一先保留为待确认选择，不能伪装成两个必做活动。
相对日期保留原话，不猜日历日期或年份。

## 规划方法

先判断是否缺少会阻断下一步的用户信息；再判断是否有充分证据证明明确范围内无解；
其余按缺口查工具或提交方案。一次只调用一个工具，不按固定次数机械查询。

- 用 catalog 发现未知品类和属性；用 search/filter/rank 区分搜索、筛选和排序。
- 属性按真实类型精确匹配。`attrs={"max_people": 8}` 是等值条件，不是容量下限。
- 正向 tags 多项为任意命中；不把它当作同时满足所有标签。
- 两地路程与候选自身距离不同。多活动费用按整份方案检查，不重复使用预算额度。
- 空结果和工具不可用都不自动证明无解；不编查询历史，不擅自放宽硬要求。
- 本地候选工具不能补查远程候选编号。实时天气不等于未来预报。
- 未结构化属性要求可据证据参与选择，但关键硬要求无法确认时应 ask，不能靠内部 reason 绕过。
- ask 的输出只结束本次执行；本轮没有增加自动接续用户回答的多轮入口。

## 表达与纪要

表达只使用实际传入的事实，日期未知时写成临时建议。未知费用不变成免费，人均和总价不能互换。
`unverified` 非空时提醒用户。规划器知道的工具事实或 unknowns，不代表表达器也收到。

纪要区分聊天已确认事项与程序建议。只有有明确任务依据才生成待办，明确认领才分配负责人；
未定负责人留空字符串，任务截止时间未明确则为 null，不能用活动开始时间代替。

## 示例和验证

所有人名、聊天和场景均为虚构示例。共有 20 个正例（理解 4、规划 12、表达 2、纪要 2）
及 18 个成对反例，每个反例给出输入、错误、原因和正确处理。
规划示例用真实 GroupState 字段的 JSON 展示；实际调用仍接收主循环渲染的等价文字，调用方式不变。
不要从示例的 found 分组键推断实际提示词没有展示的查询历史。

离线检查：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_prompts.py -q
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/check_tools.py
```

检查覆盖示例 schema、原话证据、退出者、二选一、新活动与偏好、候选数据和实际工具结果、
布尔属性类型、最终方案费用与时间衔接、无解的时间冲突证据，以及纪要责任和截止依据。
外部工具示例使用假的 source，不联网。原有措辞 lint 逻辑没有修改。

离线通过不能证明真实模型会遵守全部规则。本轮没有新增或运行真实模型评测，
没有测量 token、延迟或决策成功率；规划提示词包含较多边界示例，实际成本需后续实测。
合并前仍应按仓库协作规范手动运行 e01，并在有凭据的环境补做多场景行为评估。

## 另行协调的事项

查询来源和空结果的完整呈现、工具说明注入、表达节点接收 unknowns/工具事实、
通用属性硬校验、预算价格来源核验及多轮接续，需要主轴或工具层配合，未纳入本轮。
